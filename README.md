# Faev Design — сайт-портфолио Ивана Фаева

Веб-дизайн, сайты на Tilda (Zero Block) и frontend-разработка.

## Структура

```
index.html        — разметка всех секций сайта (тексты, кейсы, услуги, FAQ, контакты)
variant-2.html    — тот же сайт с другим главным экраном (тёмный, заголовок + фото по центру)
css/style.css     — стили; цвета, шрифты и отступы — в блоке :root в начале файла
js/main.js        — анимации и логика: появление при скролле, текст «из дымки»,
                    счётчики, параллакс, бегущая строка, меню, курсор на кейсах, форма
img/              — фавикон и фото: ivan-hero.webp (вырезанное, для главного экрана),
                    ivan-studio.jpg (исходник), ivan.webp (блок «Обо мне»)
img/cases/        — скриншоты кейсов (.webp)
```

## Как открыть

Откройте `index.html` в браузере — сервер и сборка не нужны.
Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Варианты главного экрана

- `index.html` — светлый: градиент «закат», большие слова «Faev® Design» по бокам от фото.
- `variant-2.html` — тёмный: чёрная карточка со скруглением, заголовок с оранжевой строкой,
  фото поверх заголовка, огромное «faevdesign» на фоне, подписи «Автор» / «Принцип».

Всё, что ниже главного экрана, в обоих файлах одинаковое. Когда выберем вариант,
второй файл удалим, чтобы не править тексты в двух местах.

## Секции

1. **Главный экран** — градиент «закат», фото Ивана по центру, вращающийся бейдж со знаком F,
   большой заголовок «Faev® Design». При скролле слова разъезжаются, фото приближается, бейдж поворачивается.
2. **Манифест + цифры** — текст появляется «из дымки» по скроллу, счётчики 5+ и 100+.
3. **Работы** — 12 кейсов-скриншотов (без ссылок на сайты): название, для кого и год.
   Картинки раскрываются снизу вверх, при наведении скриншот пролистывается до второго экрана.
4. **Бегущая строка** — ускоряется, когда листаешь страницу.
5. **Обо мне** — фото с параллаксом и текст.
6. **Услуги** — строки с ценами, при наведении заливаются цветом.
7. **FAQ** — аккордеон.
8. **Контакты + подвал**.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты, цены, вопросы | `index.html` |
| Кейсы | `index.html`, секция `works` — скопировать блок `<article class="case">`. Размеры: `case--full`, `case--lg`, `case--sm`, `case--xs` |
| Цвета и шрифты | `css/style.css`, блок `:root` |
| Отправка заявок с формы | функция `sendLead()` в `js/main.js` |

# Faev Design — сайт-портфолио Ивана Фаева

Веб-дизайн, сайты на Tilda (Zero Block) и frontend-разработка.

## Структура

```
index.html        — разметка всех секций сайта (тексты, кейсы, услуги, FAQ, контакты)
css/style.css     — стили; цвета, шрифты и отступы — в блоке :root в начале файла
js/main.js        — анимации и логика: появление при скролле, текст «из дымки»,
                    счётчики, параллакс, бегущая строка, меню, курсор на кейсах, форма
img/              — картинки сайта (фавикон, фото)
img/cases/        — скриншоты кейсов
```

## Как открыть

Откройте `index.html` в браузере — сервер и сборка не нужны.
Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Секции

1. **Главный экран** — градиент «закат», вращающаяся сфера со знаком F, большой заголовок «Faev® Design».
   При скролле слова разъезжаются в стороны, сфера увеличивается и поворачивается.
2. **Манифест + цифры** — текст появляется «из дымки» по скроллу, счётчики 5+ и 100+.
3. **Работы** — 8 кейсов, картинки раскрываются снизу вверх, при наведении — круг «Смотреть ↗».
4. **Бегущая строка** — ускоряется, когда листаешь страницу.
5. **Обо мне** — фото с параллаксом и текст.
6. **Услуги** — строки с ценами, при наведении заливаются цветом.
7. **FAQ** — аккордеон.
8. **Контакты + подвал**.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты, цены, вопросы | `index.html` |
| Кейсы | `index.html`, секция `works` — скопировать блок `<a class="case">`. Размер: `case--sm` (узкий) / `case--lg` (широкий) |
| Цвета и шрифты | `css/style.css`, блок `:root` |
| Отправка заявок с формы | функция `sendLead()` в `js/main.js` |
